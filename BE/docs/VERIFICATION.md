종단 검증 시나리오(설계서 11장 8단계 형식): 수성구 예시 필지 10개 × 조건 2개(토지소유주·직각주차 / 실무자·평행주차) = 20건 + 미지원 지역 2건.
각 건마다 주소 검색 → 필지 조회 → 검토 요청(202) → 진행 상태 → `review_result@1.0` 계약 검증 → 건폐율·용적률을 **조례 원문에서 따로 읽은 값**과 대조 → 근거 트리(법률→시행령→조례) → 근거 상세의 인용문이 원문에 그대로 있는지 → 화면에 나간 설명마다 PASS 검증 보고서 → 주차장 배치(필지 안, 법정 치수, 구획 수 일치) 순으로 확인합니다.
오류·예외(주소 없음 404, 잘못된 PNU, 422, 미지원 지역, 외부 API 인증 실패 503, 장애 시 캐시), 검수 흐름(L4 특화구역 등록 → ZONE_OVERLAY 격상), 설명 캐시 재사용도 포함합니다.

윈도우 실기 실행은 하지 못했습니다. `.github/workflows/ci.yml` 이 저장소를 GitHub 에 올리면 windows·macos·ubuntu × Python 3.11·3.12·3.13 에서 테스트와 종단 검증(윈도우는 워커 모드 포함)을 돌립니다.

## 2. 독립 감사와 반영

설계 문서 준수 감사와 윈도우 호환성 감사를 별도로 돌렸고, 지적 사항을 모두 고쳤습니다.

| 지적 | 조치 |
| --- | --- |
| (차단) 매일 재수집 시 같은 버전이 새 버전으로 들어가 승인 규칙의 시행 기간이 꺼지고 재검수 요청도 없음 | 버전 식별을 '시행일 + 공포번호'로 바꾸고, 같은 버전 재수집은 본문 대조(`v_text_match` confirmed / needs_review)만. 진짜 새 버전이면 `request_reextract` 기록 + 결과에 '새 버전 규칙 검수 전' 안내. 원본 XML 보관·해시. 회귀 테스트 3건 |
| 조건이 붙은 용도(바닥면적 한도, 도로 폭 등)를 '검토 가능'으로 표시, '공장' 조건 누락 | 조건 메모가 있으면 '조건부 검토'. 다른 조문으로 범위를 정하는 항목은 그 문구를 조건으로 보존 |
| 사실 원장을 사람이 보지 않고 규칙과 함께 자동 승인 | 규칙 승인 시 원장은 초안으로만 생성, 원장 승인은 별도 행위. 자동 초안의 제외 사유는 승인 검수자 이름으로 기록. 운영(`APP_ENV=prod`)에서 일괄 승인 금지 |
| AI 표 이미지 전사본이 원문처럼 승인·표시됨 | 대조 확인(`confirm_transcription`) 없이는 승인 불가, 대조자 기록. 근거 트리에 '표 이미지 전사본 · 대조: 이름' 표시, 원본 이미지로 연결 |
| 단서·특례 탐지 범위가 좁음 | 같은 조의 다른 항·호에 '다만'/'불구하고'가 있으면 검수 경고(승인 시 확인 필요) |
| 알림이 로그뿐 | `GET /admin/alerts` (범위 이탈, 설명 전부 실패, 원문 불일치, 재추출 요청, 실패한 검토) |
| 저장된 결과를 그대로 내보내 원장 변경 후에도 이전 설명이 보일 수 있음 | 조회 시점마다 `displayable_explanation` 뷰로 다시 거르고, 규칙 원장이 대체되면 합성 원장도 대체 |
| 공개 근거 API 가 검수 전·반려 규칙도 반환 | 승인·대체된 규칙만 |
| 토지이용계획에서만 확인된 특화구역에 고시 안내 없음 | 토지이음 열람 경로를 관련 근거로 제공, 승인 규칙 없음 안내가 격상에 가려지지 않게 순서 조정 |
| (윈도우 차단) 출력이 파이프일 때 한글 print 에서 UnicodeEncodeError | 모든 진입점에서 표준 입출력을 UTF-8 로 재설정 (`app/console.py`) |
| 생성 파일 CRLF, 관리자 고시번호가 파일 경로에 들어감, 워커 중단 시 'running' 고착·중복 실행 | `newline="\n"`, 경로에 id 사용, 조건부 UPDATE 로 원자적 작업 획득 + 시작 시 오래된 작업 재대기 + Ctrl+C 시 되돌림 |
| PostgreSQL 에서만 나는 문제 (CHECK 이름 중복, API·워커 동시 기동 시 스키마 생성 경합), Docker 볼륨 권한, compose 프로필 서비스의 오래된 이미지 | 열별 제약 이름, advisory lock 으로 스키마 생성 직렬화, 이미지 안에 볼륨 경로 미리 생성, 모든 서비스가 한 이미지 사용 |

## 3. 검증하지 못한 것 (실제 키·실기 필요)

- 도로명주소·브이월드·건축HUB **실제 API 호출** (모의 서버는 공식 문서와 실제 오류 응답을 따라 만들었으나 정상 응답 일부 형식은 문서에 없음 — `app/external/*.py` 주석 참고). 실제 키로 `python -m pytest -m real_api`.
- 국가법령정보 Open API(DRF) 실제 응답 (OC 인증값·서버 IP 등록 필요). 파서는 공식 가이드의 필드 정의로 만든 표본으로만 시험.
- Anthropic / OpenAI **실제 LLM 호출**. 작성·판정·추출 모두 결정적 가짜 모델로 흐름을 검증했고, 실제 모델 출력이 사후 검증을 얼마나 통과하는지는 키를 넣고 확인해야 합니다 (`LLM_PROVIDER=anthropic`).
- 실제 수성구 필지 10개 × 조건 2개의 **실무자 수작업 결과 대조** (설계서 11장 8단계). 종단 검증 스크립트의 필지 목록만 실제 필지로 바꾸면 같은 절차로 돌릴 수 있습니다.
- 윈도우 실기 (CI 로 대체 예정).
