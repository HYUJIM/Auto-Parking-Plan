# APP(Auto Parking Plan) 최소 MVP 기능정의서

## 1. 프로젝트 개요

### 1-1. 서비스명
**APP (Auto Parking Plan)**

### 1-2. MVP 목적
사용자가 주소를 입력하면 해당 필지의 기본 토지정보와 건축·주차 관련 핵심 법규를 확인하고, 해당 토지에서 검토 가능한 주요 이용 용도를 한 화면에서 확인할 수 있는 웹 기반 초기검토 서비스를 구현한다.

이번 MVP에서는 건축·주차 배치안 자동 생성보다 **주소 기반 토지정보 조회와 법규 검토 기능의 정확성 및 사용성 검증**을 우선한다.

### 1-3. MVP 핵심 가치

**주소 입력 한 번으로 초기 토지정보와 핵심 법규를 한 화면에서 확인**

기존 방식:

주소 확인  
→ 토지정보 사이트 조회  
→ 관련 법률 확인  
→ 지자체 조례 검색  
→ 적용기준 정리

APP MVP:

**주소 입력 → 토지정보 조회 → 핵심 법규 검토 → 결과 확인**

# 2. MVP 서비스 범위

## 포함 기능

1. 서비스 초기 화면
2. 주소 검색 및 필지 선택
3. 기본 대지정보 조회
4. 핵심 법규 검토
5. 법규 적용 근거 표시
6. 토지이용 관련 정보 표시
7. 최종 결과 화면
8. 검토 유의사항 및 사용자 확인 필요 항목 표시

## 제외 기능

이번 최소 MVP에서는 다음 기능을 구현하지 않는다.

- 건축 배치안 자동 생성
- 주차 배치안 자동 생성
- A/B/C 대안 비교
- AI 추천안
- 사업성 분석
- 공사비 산출
- 수익성 분석
- 3D 모델 생성
- 상세 설계
- PDF 자동 보고서
- DXF 출력
- 회원가입 및 결제
- 프로젝트 저장 및 불러오기

위 기능은 법규 검토 MVP 검증 이후 단계적으로 추가한다.

# 7. 법규 검토 기능

## 7-1. 기능 목적

해당 필지에 적용되는 핵심 건축·주차 관련 기준을 자동으로 정리해 사용자가 초기검토에 활용할 수 있도록 한다.

법규 검토 결과는 단순 수치만 보여주는 것이 아니라 반드시 다음 세 가지를 함께 표시한다.

**① 적용 기준  
② 적용 근거  
③ 해당 토지에 적용된 결과**

---

# 8. MVP 핵심 법규 검토항목

초기 MVP에서는 모든 법률을 다루기보다 자동 검토가 비교적 명확한 항목부터 구현한다.

## ① 건축물 용도 관련

표시 예시:

**토지 이용 가능 용도**

용도지역: 제2종일반주거지역

주요 검토 가능 용도 예시:

- 단독주택
- 공동주택
- 제1종 근린생활시설
- 일부 제2종 근린생활시설

### 표시 방식

단순히 "가능"이라고 단정하지 않고,

**검토 가능 / 조건부 검토 / 추가 확인 필요**

등으로 구분한다.

세부 건축물 용도별 허용 여부는 지자체 조례 및 개별 조건에 따라 달라질 수 있으므로 최종 확인 필요 문구를 함께 표시한다.

---

## ② 건폐율

표시 내용:

- 법정 기준
- 해당 필지 적용 기준
- 법적 근거

예시:

**건폐율**

기준  
60% 이하

대지면적  
500㎡

최대 건축면적 참고값  
300㎡

근거  
관련 법령 및 ○○시 도시계획조례

※ 실제 허용값은 개별 필지 조건에 따라 달라질 수 있음.

---

## ③ 용적률

표시 내용:

- 법정 기준
- 해당 필지 적용 기준
- 참고 연면적
- 법적 근거

예시:

**용적률**

기준  
250% 이하

대지면적  
500㎡

최대 연면적 참고값  
1,250㎡

근거  
관련 법령 및 ○○시 도시계획조례

---

## ④ 주차대수

건축물 용도가 확정되지 않은 MVP 단계에서는 정확한 필요 주차대수를 자동 확정하지 않는다.

대신:

**건축물 용도 선택 시 적용되는 주차기준 확인 기능**

또는

**주차 기준 확인 필요**

형태로 제공한다.

향후 사용자가 건축물 용도를 선택하면

- 용도
- 연면적
- 세대수

등을 기반으로 필요 주차대수를 계산하는 기능으로 확장한다.

---

## ⑤ 주차구획 크기

법규 기준값을 표시한다.

예:

**일반형 주차구획**

기준값 표시

**확장형 / 장애인전용 / 경형**

각 기준을 별도 확인 가능하도록 한다.

MVP에서는 실제 배치 여부까지 판단하지 않는다.

---

## ⑥ 차로 폭

관련 기준값을 표시한다.

실제 필지에서 해당 기준 충족 여부는 진출입 위치와 배치안이 있어야 판단 가능하므로:

**기준정보 제공 + 추후 배치 단계 검토**

로 표시한다.

# 9. 사용자 별도 확인 항목

자동 판단하기 어려운 항목은 결과 화면에서 명확히 분리한다.

## 별도 확인 필요

### ① 도로 및 진출입 조건
- 도로 폭
- 접도 조건
- 차량 진출입 가능 위치

### ② 건축선 및 이격거리
- 도로경계
- 인접대지경계
- 별도 건축선 지정 여부

### ③ 높이 및 일조 조건
- 일조권
- 높이 제한
- 사선 제한 등

### ④ 추가 지역 규제
- 지구단위계획
- 특별계획구역
- 경관지구
- 특화구역
- 기타 개별 인허가 조건

화면 표시:

**⚠ 추가 확인이 필요한 항목입니다.**

APP의 자동검토 결과만으로 최종 인허가 가능 여부를 판단하지 않도록 한다.

# 17. MVP 검증 목표

이번 MVP에서는 기능 수보다 다음을 검증한다.

### 검증 1
사용자가 주소만으로 필요한 토지정보를 쉽게 확인할 수 있는가?

### 검증 2
핵심 법규를 기존 방식보다 편하게 확인할 수 있는가?

### 검증 3
사용자가 법규 수치뿐 아니라 적용 근거까지 확인할 수 있는가?

### 검증 4
결과 화면만 보고 해당 토지의 초기 활용 가능성을 이해할 수 있는가?

### 검증 5
설계사무소 실무자가 실제 초기검토 과정에서 다시 사용할 의향이 있는가?

---

# 18. 최소 MVP 성공 기준

MVP는 다음 조건을 만족하면 1차 성공으로 판단한다.

- 사용자가 주소를 입력할 수 있다.
- 해당 주소의 필지정보를 불러올 수 있다.
- 용도지역을 확인할 수 있다.
- 건폐율 및 용적률 등 핵심 기준을 확인할 수 있다.
- 주요 토지이용 용도를 확인할 수 있다.
- 각 결과의 법규 근거를 확인할 수 있다.
- 자동검토가 어려운 항목은 별도로 구분된다.
- 실제 대구 수성구 필지에서 반복 테스트할 수 있다.

# 19. MVP 핵심 화면 구성

최종적으로 사용자가 경험하는 화면은 **3개 화면 중심**으로 단순화한다.

### ① 초기 화면

**주소 하나로 시작하는 건축 초기검토**

[ 주소 입력 ]

✓

# 20. APP MVP 핵심 정의

이번 MVP의 목표는 **설계안을 자동으로 만들어주는 것**이 아니다.

우선,

**“이 땅에 어떤 기준이 적용되고, 그 기준이 어디에서 나온 것인지 빠르게 확인할 수 있는 서비스”**

를 구현한다.

법규 검토 기능과 데이터의 신뢰성을 먼저 검증한 뒤,

**법규 검토 → 건축 가능범위 → 건축 매스 → 주차 배치 → 대안 비교**

순으로 기능을 확장한다.

APP의 장기적인 경쟁력은 단순한 AI 생성 기능이 아니라,

**“법규 근거가 실제 설계 판단과 배치 결과로 연결되는 구조”**

에 두는 것을 원칙으로 한다.
