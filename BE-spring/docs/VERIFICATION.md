## 3. 파이썬판과 다르게 나오는 것

- **목록 순서**: 파이썬판은 규칙 값·근거 목록을 DB 가 돌려준 순서로 써서, SQLite 에서는 '검토 가능한 주요 용도'가 값 키 문자열 순(호 번호 2.1, 2.10, …, 2.2), PostgreSQL 에서는 대체로 저장 순서였고 실행 계획에 따라 한 항목이 앞으로 오기도 했다.
  스프링판은 행 id 를 시간순 UUID 로 만들고 id 순(=저장 순서, 법령 호 번호 순)으로 고정했다. 목록의 항목·상태·근거는 같다.
- **`ruleset_hash`**: 규칙 id(무작위 UUID)로 만드는 값이라 DB 가 다르면 다르다 (같은 DB 안에서의 재현성 용도). 두 구현 모두 같은 방식으로 계산한다.
- **배치 엔진의 마지막 자리**: 좌표 투영의 수학 함수 마지막 비트(맥 libm) 차이로 140개 사례 중 2개에서 배치 탐색 후보가 달라진다 (1개는 구획 66 대 65). 예시 필지 12개에서는 모두 같았다.
